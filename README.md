# LampStore

**Магазин расширений для Lampa** — плагины, полезные скрипты и внешние ссылки в одном каталоге.

Подключите магазин один раз, а затем открывайте его прямо из **Настроек Lampa**. Новые расширения появляются в каталоге после обновления репозитория — пользователю не нужно искать и добавлять их вручную.

## Установка

Установите в Lampa один файл:

```text
https://raw.githubusercontent.com/rusanoff1983-del/LampStore/main/store.js
```

После подключения откройте **Настройки → LampStore**. Выберите нужное расширение и подтвердите установку.

> Если Lampa не поддерживает встроенный магазин расширений, LampStore сообщит об этом при открытии.

## Что есть в магазине

- плагины для интерфейса и навигации;
- скрипты для настройки и расширения Lampa;
- проверенные внешние расширения;
- карточки с описанием и скриншотами, где они доступны.

## Для владельца репозитория: как добавить расширение

Каждое расширение хранится в отдельной папке внутри `plugins/`.

### Плагин из этого репозитория

```text
plugins/
└── my-plugin/
    ├── plugin.js
    ├── text.txt
    └── screenshot.webp   # необязательно
```

- `plugin.js` — файл плагина. Если в папке лежит один JavaScript-файл, его имя может быть любым.
- `text.txt` — первая строка является названием, остальной текст — описанием.
- Скриншот необязателен. Поддерживаются: `screenshot.png`, `screenshot.jpg`, `screenshot.webp`, `screen.png`, `preview.png`.
- Для иконки используйте `icon.png`, `icon.jpg` или `icon.webp`.

### Внешний плагин

Если файл плагина находится у автора, добавьте ссылку:

```text
plugins/
└── external-plugin/
    ├── url.txt
    ├── text.txt
    └── screenshot.png    # необязательно
```

В `url.txt` должна быть одна прямая ссылка на JavaScript-файл расширения.

## Как обновляется каталог

Каталог формируется GitHub Actions из папок в `plugins/`. Добавьте или измените расширение, отправьте изменения в ветку `main` — после сборки оно появится в LampStore.

## Установка через Lampac Web

Чтобы магазин автоматически подключался на всех устройствах, добавьте в `/opt/lampac/plugins/override/lampainit.js` после `clearInterval(timer);`:

```js
Lampa.Utils.putScriptAsync([
  'https://raw.githubusercontent.com/rusanoff1983-del/LampStore/main/store.js'
], function () {});
```

Затем перезапустите Lampac:

```bash
systemctl restart lampac
```

---

LampStore не хранит плагины пользователя и не требует отдельного аккаунта: каталог загружается напрямую из этого репозитория.
