# LampStore

**Мой каталог расширений для Lampa.**

Это не шаблон и не конструктор магазина. `LampStore` подключает именно этот каталог с плагинами из репозитория `rusanoff1983-del/LampStore`.

## Подключить LampStore

Добавьте в Lampa этот файл:

```text
https://raw.githubusercontent.com/rusanoff1983-del/LampStore/main/store.js
```

После подключения в **Настройках Lampa** появится пункт **LampStore**. В нём можно выбрать и установить нужное расширение.

## Что внутри

В каталоге собраны плагины, скрипты и внешние расширения для Lampa: интерфейсные улучшения, навигация, стриминги и другие полезные дополнения. Описание и скриншот доступны в карточке расширения, если автор их добавил.

## Важно: это не копия для развёртывания

Просто скопировать или форкнуть этот репозиторий недостаточно, чтобы получить свой магазин:

- `store.js` привязан к каталогу `extensions.json` именно этого репозитория;
- после копирования он либо продолжит открывать LampStore, либо перестанет работать, если изменить адрес без настройки остальных файлов;
- самостоятельная версия требует отдельной настройки ссылок, каталога и сборки.

Для переноса или самостоятельного развёртывания нужен готовый архив со всеми файлами и инструкцией. Такой вариант должен публиковаться отдельным релизом; копия репозитория сама по себе не является готовой установкой.

## Обновления

Каталог поддерживается в этом репозитории. Когда в `main` добавляются или обновляются плагины, GitHub Actions пересобирает `extensions.json`, и изменения становятся доступны в LampStore.

> Если в вашей версии Lampa нет встроенного магазина расширений, LampStore сообщит об этом при открытии.
