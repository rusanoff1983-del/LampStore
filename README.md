# LampStore

Магазин расширений для Lampa: можно подключить готовый каталог или сделать свою копию.

## Подключить готовый LampStore

Добавьте в Lampa эту ссылку:

```text
https://cdn.jsdelivr.net/gh/rusanoff1983-del/LampStore@main/store.js
```

После подключения в **Настройках Lampa** появится пункт **LampStore**. В нём можно выбрать и установить нужное расширение.

## Сделать свой магазин

1. Скачайте архив последнего релиза из [Releases](https://github.com/rusanoff1983-del/LampStore/releases/latest).
2. Распакуйте его в новый **публичный** GitHub-репозиторий и отправьте файлы в ветку `main`.
3. Подключите в Lampa свою ссылку:

```text
https://cdn.jsdelivr.net/gh/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ@main/store.js
```

Ничего в `store.js` менять не нужно: он сам берёт `extensions.json` из того же репозитория, откуда был подключён. Можно также сделать fork вместо архива.

## Как добавить плагин в магазин

Есть два способа.

### 1. Положить файл плагина в репозиторий

Создайте отдельную папку внутри `plugins/` и положите в неё JavaScript-файл плагина. Рядом можно добавить `text.txt` с названием и описанием, а также скриншот:

```text
plugins/
└── my-plugin/
    ├── plugin.js
    ├── text.txt
    └── screenshot.png
```

### 2. Добавить ссылку на внешний плагин

Если плагин хранится у другого автора, добавьте строку в `links/links.txt`:

```text
Название плагина | https://site.example/plugin.js | Короткое описание
```

После отправки изменений в `main` GitHub Actions обновит `extensions.json`.

## Один store.js — весь магазин на устройствах

Достаточно один раз подключить `store.js` в Lampa на каждом нужном устройстве. После этого все добавленные вами плагины — любимые, избранные или новые — будут появляться в LampStore автоматически. Не нужно устанавливать каждый плагин отдельно на каждом устройстве.

> Если в вашей версии Lampa нет встроенного магазина расширений, LampStore сообщит об этом при открытии.
